# ADR 002: 오염물질별 다른 룰 적용 전략

## 상태

승인됨

## 컨텍스트

다양한 오염물질(TVOC, eCO2, 온도, 습도, 기압)에 대해 이상 패턴을 감지해야 합니다. 하지만 모든 오염물질에 대해 동일한 룰을 적용하는 것은 적절하지 않습니다.

예를 들어:
- TVOC와 eCO2는 **임계치 초과**와 **급상승** 모두 중요
- 온도, 습도, 기압은 **급상승**만 중요 (임계치는 환경에 따라 달라질 수 있음)

## 결정

오염물질별로 다른 룰을 적용합니다:

- **TVOC, eCO2**: 
  - `ThresholdRule` + `RapidRiseRule` 모두 적용
  - 임계치 초과 시 WARNING 레벨 알림
  - 급상승 시 DANGER 레벨 알림

- **온도, 습도, 기압**:
  - `RapidRiseRule`만 적용
  - 급상승 시 DANGER 레벨 알림
  - 임계치 초과 룰은 적용하지 않음

## 고려한 대안

### 대안 1: 모든 오염물질에 동일한 룰 적용

**장점**:
- 구현이 단순함
- 일관성 있는 처리

**단점**:
- 온도, 습도, 기압의 경우 절대값보다 변화량이 중요
- 환경에 따라 적정 온도/습도가 다름
- 불필요한 알림 발생 가능

### 대안 2: 현재 선택 (오염물질별 맞춤 룰)

**장점**:
- 각 오염물질의 특성에 맞는 룰 적용
- 불필요한 알림 감소
- 확장 가능 (새로운 오염물질 추가 시 적절한 룰 선택)

**단점**:
- 룰 설정이 복잡해질 수 있음
- 새로운 오염물질 추가 시 룰 선택 필요

## 결과

- `RulePresets.defaultRules()`에서 오염물질별로 적절한 룰을 구성
- TVOC, eCO2는 2개의 룰 (임계치 + 급상승)
- 온도, 습도, 기압은 1개의 룰 (급상승만)
- 총 7개의 룰이 기본 세트로 제공됨

## 참고

- 향후 새로운 오염물질 추가 시 `RulePresets`에서 적절한 룰 조합 선택 가능
- 사용자 정의 룰 세트도 `RuleEngine`에 전달 가능
